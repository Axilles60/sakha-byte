# Данные из общей переписки

Переписка [«Исследование цифровизации языка»](https://chatgpt.com/share/6afb6dce-61d8-83ed-8970-db2f9cbf9da2)
прочитана через браузер. Публичные карточки основных ресурсов проверены
16 ноября 2026 года. Числа и рекомендации из переписки не считаются первичным
подтверждением: отдельно проверены доступность карточки, назначение и заявленные
условия. Файлы датасетов не скачивались, содержимое закрытых репозиториев не изучено.

`configs/dataset_registry.json` — справочный реестр источников. Выбранные источники
подключены к новой команде `fetch-source` через `configs/dataset_downloads.json`.
Старая `download-data` сохранена для UniMorph. Реальные ревизии, манифесты и
статистика создаются только на сервере. Конвертеры описаны в `docs/data_pipeline.md`.

## Предлагаемый первый набор

1. **Языковая адаптация Qwen:** `ailabykt/sakha-corpus-mono` как основной кандидат.
   Карточка указывает CC BY 4.0, ограниченный доступ и ошибки OCR для natlib.
   До загрузки пользователь принимает условия HF; read token доступен только серверу.
   Источники, качество и точные дубли проверяются до разбиения по документам.
2. **Билингвальная адаптация, отдельный этап:** `ailabykt/sakha-russian-parallel`.
   CC BY 4.0, gated; карточка предупреждает об OCR и автоматическом выравнивании.
   Не смешивать с монокорпусом без проверки пересечений.
3. **Диагностика:** `UD_Yakut-YKTDT` для морфологии/синтаксиса,
   Sakha NER/SAAS для извлечения сущностей и тональности.
   Добавлены адаптеры выбора леммы, тональности и типа уже выделенной сущности.
   Полноценные dependency parsing и NER extraction этим не измеряются.
   README NER/SAAS указывает CC BY-NC 4.0.
4. **Понимание текста:** сохранить текущий 16-примерный черновик только для
   технической проверки; подготовить независимый, проверенный носителями тест.
   Найденные корпуса не заменяют такой gold set автоматически.
5. **Экспертная оценка:** изучить `loalkota/sakha-judge` на уровне файлов.
   Это смешанная предварительная публикация: обучающие компоненты и человеческие
   оценки должны оставаться раздельными. Синтетическая морфология не становится
   экспертной разметкой только из-за наличия в том же репозитории.

Ссылки и требования перечислены в реестре. Дополнительные WMT и averoo корпуса
оставлены кандидатами: нужно уточнить лицензии и пересечения с основными данными.
У WMT публичный viewer показывает train, а не отдельный независимый test.

## Что требует отдельной разработки

В общей переписке Sakha-MMLU, Sakha-NLI, Sakha-Logic и многие другие названия
представлены как предложения для будущего комплекса. Их нельзя считать уже
скачиваемыми размеченными тестами. Belebele, KazMMLU и MERA — ориентиры дизайна;
наличие упоминания не подтверждает существование якутских версий.

Собственный SakhaBench из карточки embedding-модели нельзя автоматически трактовать
как независимый универсальный тест LLM. X-WMT имеет смысл рассмотреть в отдельном
эксперименте перевода с точным выбором доступных направлений.

Наша согласованная основная схема сохраняется: ансамбль Bwen + EvaByte против
Qwen до/после языковой адаптации. В текущем коде ансамбль объединяет только оценки
вариантов ответа. Для перевода, NER или свободной генерации потребуется отдельное
правило совместного ответа и оценки; существующая функция ensemble туда не переносится.

## Работа только на сервере

После доступа к IMMERS:

- получить разрешённый доступ HF, разрешить ревизии источников и сохранить lock-файлы;
- загрузить выбранные файлы на постоянный удалённый том;
- проверить фактические схемы, объёмы, языки и источники;
- исключить тестовые документы и их переводы из всех обучающих корпусов;
- создать train/validation/test по документам, сохранив исходные идентификаторы;
- проверить добавленные конвертеры на фактических схемах и выполнить серверные тесты.

Локально не создаются корпуса, выгрузки общей переписки, веса, окружения или
результаты. Этот файл и JSON-реестр содержат только описание и конфигурацию источников.
